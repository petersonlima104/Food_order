# Food Order - 
# 🍕 Pizzaria Delivery – Sistema de Pedidos Personalizados

Sistema online para montagem de pizzas, permitindo escolher até 4 sabores, borda recheada com adicional e bebida opcional.

---

## ✅ Funcionalidades

- Escolha do tamanho da pizza.
- Seleção de até **4 sabores** (bloqueio automático acima disso).
- Escolha de borda recheada (com adicional).
- Escolha de bebidas (com adicional).
- Carrinho funcional:
  - Adicionar pizzas
  - Remover itens
  - Finalizar pedido via WhatsApp
- Registro temporário com LocalStorage.
- Design responsivo.

---

## 🛠️ Tecnologias

- HTML5  
- CSS3 / Bootstrap  
- JavaScript  

---

## 🧠 Lógica de Destaque

- Limite de sabores com validação automática.
- Cálculo dinámico de adicionais.
- Mensagem automática formatada para envio ao WhatsApp.
